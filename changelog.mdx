<Update label="July 20, 2026" description="v0.18.0">
  ### Design cohesion, Monitoring polish, and website updates

  **A more cohesive app design**

  Breaknine’s product UI is more consistent end-to-end — refreshed design tokens, typography, compact controls, and shared navigation so screens feel like one system. Choose **Light**, **Dark**, or **System** appearance from the sidebar, Settings, or mobile More menu; your preference sticks across sessions.

  **Monitoring polish**

  - **Activity worth watching** — the developing-trends rail has clearer labeling, copy, and an info tooltip on how related updates are grouped and how to read momentum (including on storyline detail pages).
  - **View source on review** — updates waiting for review now link out to the original source, so you can inspect the article before approving or dismissing.
  - **Clearer M&A badges** — acquisition and merger updates classify as **M&A** instead of looking like competitive moves.

  **Website: monitoring hero and how-it-works**

  [breaknine.ai](https://breaknine.ai) now leads with an interactive **30-day monitoring** hero — explore recent signals on a timeline and see how they become actionable context. The how-it-works section also uses interactive **Monitor → Understand → Reach out** panels instead of static screenshots.
</Update>

<Update label="July 13, 2026" description="v0.17.0">

  **News Feed is now Monitoring**

 For **Affinity** users, email interactions now sync into each prospect's activity timeline in Breaknine. <Update label="June 26, 2026" description="v0.15.0">
  ### Daily digest B9 suggestions, CRM sync preview, and Affinity reliability

  **B9 suggestions in your daily email**

  Daily update emails now includes a dedicated **B9 suggestions** section first, if suggestions exist. Each suggestion is grounded in fresh company updates, CRM notes, and prior outreach — and links straight to the saved next action in the app so you can review evidence and act in one click. Breaknine suggests an outreach path based on gathered context, company updates, notes, and user set reach out triggers.

  ![B9 suggestions in daily email](https://pub-9bba086e01f6491e9984367c6bed7fc0.r2.dev/6_26_26/Screenshot%202026-06-26%20at%203.37.13%E2%80%AFPM.png)

  **Preview Affinity and Attio companies before you sync**

  When you connect **Affinity** or **Attio**, you can preview what Breaknine will pull in before a sync starts. Review the companies, fields, and records that will be imported so you know exactly what to expect before data lands in your workspace.

  **Affinity sync reliability**

  Affinity owner matching now prefers stable **owner IDs** instead of email alone. If Affinity returns different email aliases for the same owner across API calls, your list entries still sync correctly instead of being filtered out.

  **Sequence start fix**

  Fixed a regression where **Start sequence** (in the outreach panel) could appear to succeed in the UI without actually activating the sequence on the server. Starting a sequence now persists through the API as expected, including when Gmail send is unavailable — with a clear tooltip explaining why start is disabled.
</Update>

  **Email sequencing**

  Breaknine now supports multi-step **email sequences** — build a canvas of timed outreach steps, assign recipients, and track progress from a sequence ledger. Start sequences from scratch or from outreach you have already drafted, and manage active, paused, and completed runs in one place.

<Update label="May 29, 2026" description="v0.11.0">
  ### Audit log, recoverable deletion, and Affinity configuration improvements

  **Audit log in Settings**

  You can now review an **audit log** under **Settings** to see important actions taken in your workspace. The log helps you trace who changed what and when, without digging through individual screens. You will also be able to **restore previous versions** of the workspace.

  **Recoverable deletion**

  When you delete supported user data, Breaknine can capture a recovery bundle so deleted items may be restored. Delete confirmations explain when recovery is available. Integration disconnects and purges stay non-recoverable by design; integration data deletions follow the new recoverable flow where supported.

  **Affinity configuration errors**

  The Affinity configuration modal now shows clear error messages instead of generic `[object Object]` text when something fails during setup or save. So you're now able to see exactly what is failing & we can better triage failed set-ups. Affinity read requests are also cached for faster, more reliable configuration loading. Meaning, we don't use as many API calls when syncing Affinity data.

<Update label="Apr 24, 2026" description="v0.6.0">
  ### Outreach tab, Affinity sync improvements, Custom email snippets, and more

  **Outreach tab**

  We've implemented an outreach section where you can not only do your **outreach based on company updates & next actions (or reminders) but also outreach to any prospect.** Outreaches are organized into two sections; "Actions" referring to B9 suggested next actions or your set next actions from your CRM, and "Updates" referring to B9 sourced prospect updates to reach out with. The prospect update or notes you use to inform the outreach shows a status badge — New or Used — so you can tell at a glance which updates & notes have been referenced in past emails. The interface also tracks email events for sent outreaches, including replies.

  <video controls width="100%">
    <source src="https://pub-9bba086e01f6491e9984367c6bed7fc0.r2.dev/Outreach%20Updates.mp4" type="video/mp4" />
  </video>

  **Affinity Reminders & Notes sync**

  If you have Affinity connected, your Next Actions (reminders) & notes sync into Breaknine. Previously, the Next Actions field was missing from the Affinity configuration panel — this is now resolved and reminders will appear alongside your other Affinity data. You can get to reminders / next actions via the "next actions" tab and these also inform the outreach tab. 

  **Custom email snippets**

  You can now create your own **reusable text snippets** and insert them anywhere in an outreach email. Type / followed by a trigger word to pull up your snippet menu and select the one you want. Snippets support custom variables so you can personalize them on the fly without rewriting the same blocks of text every time. You can create snippets in settings > snippets > create new snippet.

  **Dismiss tasks without opening them**

  You can now dismiss notifications directly from the Tasks page without clicking into each one first. A dismiss button is available inline on each task in the list.

  The daily digest has been further refined. Sections are more clearly delineated, and the digest now incorporates signals from your synced email and calendar alongside the existing trigger updates.
